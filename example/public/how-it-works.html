One block. Everything connected.

Run this in your app. The standard shadcn CLI installs dependencies and writes the complete integration into your project.

bun run test:next

# Stop the test app's dev server, then:
bun run test:next:clean

Setup builds and packs the kit, creates a fresh Next.js + Base UI/Nova app, installs through shadcn, and runs next build. 02 / Render

Import it. Give it a schema.

This first example uses the existing Contact card schema URL. The generated resolver loads it and its references; the generated kit renders the form.

Your component · target usage

You get editable fields, nested objects, validation feedback, and Save/Reset. Save calls your handler only with valid data. This example logs the payload; connect your API when you want to persist it.

No annotation required to start. Default input and display work from the schema. Add annotations when you want labels, grouping, widgets, or named views.

03 / Make it yours

Own the source. Skip the ceremony.

  • Change a control: edit your local Input. Surface uses that same Input.
  • Change presentation: register your annotation in the generated resolver file. Let core apply it.
  • Change a mapping: edit the generated kit. No fork and no second lookup engine.
  • Use local schemas: seed the generated schema resolver. Remote URLs are convenient, not mandatory.
What “just works” must include
  • Installation honors components.json paths and imports, installs npm dependencies, and makes no silent changes to existing primitives.
  • The first import needs no provider or resolver boilerplate. The generated module creates one configured Surface family, not a new one on every render.
  • Schema load failures and validation errors are visible. Failed loads do not become successful-looking empty forms.
  • Remote schemas must be browser-accessible. Private/authenticated sources need your application’s fetch policy in the generated resolver; the installer cannot infer credentials.
  • Annotations are explicitly registered. Loading a schema does not invent or discover an annotation URL.
  • Your application owns persistence. The kit owns neither your database nor an implicit save endpoint.
